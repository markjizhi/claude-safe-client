# 让 Codex 帮你安装

在 Mac 上打开 Codex，复制并发送下面整段话。链接已经写在里面。

~~~text
请打开下面的 GitHub 安装说明，按文档在这台 Mac 上帮我安装并配置 Claude 安全客户端。先检查 Docker，已经装好就确认能用，没装就帮我安装并启动。然后打开客户端，帮我配置已有的静态 IP，确认运行环境能启动、代理能连通。

https://raw.githubusercontent.com/markjizhi/claude-safe-client/main/docs/codex-install.md

需要输入激活码或代理密码时，告诉我填在哪里，我在客户端窗口里输入。填完后请继续帮我检查。
~~~
